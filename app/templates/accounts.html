X / Twitter

📋 Пошаговая инструкция
  1. Шаг 1: Откройте Twitter Developer Portal → Projects & Apps → Создайте приложение
  2. Шаг 2: Включите OAuth 2.0 (с PKCE) в настройках приложения. Скопируйте Client ID и Client Secret
  3. Шаг 3: Redirect URI: http://127.0.0.1:8000/api/accounts/callback/x (для локальной разработки)
  4. Шаг 4: Настройте права (scopes): tweet.read, tweet.write, users.read, offline.access
  5. Шаг 5: Для загрузки медиа (фото/видео): Получите OAuth 1.0a ключи:
    • Keys & tokens → API Key/Secret (Consumer Key/Secret)
    • Access Token & Secret (OAuth 1.0a)
  6. Шаг 6: Заполните все поля ниже и нажмите "Save X settings"
  7. Шаг 7: Используйте кнопку "Get X authorization link" для OAuth 2.0 авторизации
  8. Шаг 8: Проверьте кнопкой "Tweet (test)"

YouTube Shorts

📋 Пошаговая инструкция
  1. Шаг 1: Откройте Google Cloud Console → Создайте проект
  2. Шаг 2: Включите YouTube Data API v3 (APIs & Services → Library)
  3. Шаг 3: Создайте OAuth 2.0 Client (Credentials → Create Credentials → OAuth client ID → Desktop app)
  4. Шаг 4: Скопируйте Client ID и Client Secret
  5. Шаг 5: Получите Access Token и Refresh Token (через локальное приложение или скрипт авторизации)
  6. Шаг 6: Вставьте все 4 значения в поля ниже и нажмите "Save YouTube"




VK

📋 Пошаговая инструкция
  1. Шаг 1: Откройте VK для разработчиков → Мои приложения → Создать приложение
  2. Шаг 2: Скопируйте Client ID (ID приложения) и Client Secret (Защищенный ключ) в соответствующие поля ниже, нажмите "Save VK settings"
  3. Шаг 3: Найдите Group ID: откройте вашу группу ВКонтакте, в адресной строке будет vk.com/club123456 или vk.com/public123456 — число это ID группы
  4. Шаг 4 (КРИТИЧНО): Нажмите кнопку "Get link to obtain Access Token (Implicit)" ниже
    ⚠️ ВНИМАНИЕ: Токен ДОЛЖЕН иметь права: photos, wall, groups, offline, video
    Без прав photos и video загрузка медиа НЕ БУДЕТ РАБОТАТЬ!
  5. Шаг 5: После авторизации скопируйте access_token из адресной строки (после #access_token=...)
  6. Шаг 6: Вставьте токен в ОБА поля: "Access Token" И "User Access Token" (оба обязательны!)
  7. Шаг 7: Нажмите "Save VK settings", затем используйте кнопку "Check token" чтобы убедиться что токен имеет все права
  8. Шаг 8: Проверьте кнопкой "Post to group (test)"

Facebook

📋 Пошаговая инструкция
  1. Шаг 1: Откройте Meta for Developers → Мои приложения → Создать приложение
  2. Шаг 2: Выберите тип "Business" или "Other" → заполните данные приложения
  3. Шаг 3: Добавьте продукт "Facebook Login" в настройках приложения
  4. Шаг 4: Получите Page Access Token:
    • Tools → Graph API Explorer
    • Выберите вашу страницу Facebook
    • Добавьте права: pages_manage_posts, pages_read_engagement
    • Generate Access Token → скопируйте токен
  5. Шаг 5: Найдите Page ID: Settings вашей страницы → внизу страницы Page ID
  6. Шаг 6: Важно: Используйте Page Access Token (не User Token). Для загрузки медиа нужна роль админа страницы
  7. Шаг 7: Вставьте данные в поля ниже, нажмите "Save Facebook", затем "Test post"

Reddit

📋 Пошаговая инструкция
  1. Шаг 1: Откройте Reddit App Preferences
  2. Шаг 2: Нажмите "create another app..." → Выберите тип "script"
  3. Шаг 3: Заполните название, redirect uri: http://localhost:8080
  4. Шаг 4: Скопируйте Client ID (под названием приложения) и Client Secret
  5. Шаг 5: Укажите ваш Reddit Username и Password
  6. Шаг 6: Укажите название Subreddit (без r/, например: gamedev)
  7. Шаг 7: Убедитесь что у вас есть права на постинг в указанном subreddit
  8. Шаг 8: Нажмите "Save Reddit"





Telegram

📋 Пошаговая инструкция
  1. Шаг 1: Откройте Telegram, найдите бота @BotFather
  2. Шаг 2: Отправьте команду /newbot и следуйте инструкциям
  3. Шаг 3: Скопируйте Bot Token (формат: 123456789:ABCdefGHIjklMNOpqrsTUVwxyz)
  4. Шаг 4: Добавьте бота в вашу группу/канал и дайте права на отправку сообщений
  5. Шаг 5: Получите Chat ID:
    • Добавьте @RawDataBot в группу → он покажет chat_id
    • Или используйте метод getUpdates API
  6. Шаг 6: Вставьте Bot Token и Chat ID в поля ниже, нажмите "Save Telegram"
