Steam — reports

{% if steam_key_hint %}✓ key {{ steam_key_hint }}{% endif %}

How to get the key

  1. Steamworks → Users & Permissions → Manage Groups ↗ → create a group, e.g. “Financial API”
  2. Give the group the General and Financial permissions (no users or apps)
  3. In the group → Create WebAPI Key, optionally restrict it by IP
  4. Paste the key here and click “Check”
  5. In Projects, set the Steam App ID for each game

Steam publishes each day’s data the next day. IndiePulse loads the wishlist history in the background (one request per day since the page went live) — for a 2019 game that’s about 10–20 min; progress shows on Home.

This key doesn’t give page visits and impressions — the “IndiePulse ← Steam” bookmarklet collects them: Steam traffic.

Facebook

Loading...

Easy setup

Manual fields (advanced)

Easy Setup (one-time, ~5 min)

  1. Create an app at Meta for Developers (type: Business). Keep it in Development mode — no App Review needed when you are the app admin and Page admin.
  2. Copy App ID and App Secret from App Settings → Basic into the fields here.
  3. Open Graph API Explorer, pick your app, click Generate Access Token with permissions: pages_show_list, pages_manage_posts, pages_read_engagement.
  4. Paste the token here and click Fetch My Pages.
  5. Click Use as RU / Use as EN next to your pages. Done.
The app exchanges your token for a long-lived one automatically — Page tokens obtained this way effectively don't expire. Re-run this flow only if Facebook invalidates the token (password change, revoked permissions).

Setup (needs Meta App Review)

  1. The IG account must be Business/Creator and linked to a Facebook Page (Facebook section above).
  2. The instagram_business_content_publish permission goes through Meta App Review (~2–4 weeks).
  3. Get the IG Business Account ID: Graph API Explorer → GET /{page-id}?fields=instagram_business_account.
  4. Use the linked page’s Page Access Token as the token.
Until the review passes, Reels go to the export folder (upload them manually from your phone). Once approved — full auto-posting.

Works in draft (inbox) mode: videos go straight to your TikTok inbox, then you add sound/caption in the app and publish. No TikTok audit needed for this. Connect and post from 🎵 TikTok: it also shows whether a draft went live and its numbers.

Access token: {{ tiktok_token_hint }} (refreshes automatically)
{% endif %}

Setup

  1. Create an app at developers.tiktok.com
  2. Add the Login Kit and Content Posting API products
  3. Enable the user.info.basic and video.upload scopes (inbox mode, no audit needed). For views and followers on 🎵 TikTok also video.list, user.info.stats, user.info.profile.
  4. In Login Kit, set the Redirect URI — the same one as in the field on the left
  5. Copy the Client Key + Secret here → Save → Connect TikTok
TikTok requires an HTTPS redirect for production apps — for local use, switch the app to Sandbox mode and add your TikTok account to target users, or run an https tunnel (ngrok/cloudflared) and use its URI.
Without keys the factory keeps saving videos to render/ for manual upload.

Video editor

Opens from the video tile in “📷 Post” and on “🎬 Video”: format (original / 16:9 / 9:16 / 1:1), crop, trim, music from these folders, on-screen text.

A video over a network’s limit is re-compressed to fit when publishing (Discord, Telegram 50 MB, Bluesky 100 MB…). If even that doesn’t help, the post fails with an error instead of going out without the video. The editor shows in advance what will happen on each network.
