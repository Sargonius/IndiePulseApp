YouTube

Loading...

Setup Instructions

  1. Open Google Cloud Console
  2. Create project, enable YouTube Data API v3
  3. Create OAuth 2.0 Client, добавь redirect URI http://127.0.0.1:8000/api/accounts/callback/youtube
  4. Сохрани Client ID + Secret → Connect YouTube (токены заполнятся сами)
Ошибка invalid_grant при загрузке = refresh token протух или отозван — просто нажми Connect YouTube ещё раз. Если OAuth-приложение в Google Console стоит в статусе Testing, refresh token живёт всего 7 дней — переключи консент-скрин в In production (аудит не нужен), и токен станет вечным.

Facebook

Loading...

Easy setup

Manual fields (advanced)

Easy Setup (one-time, ~5 min)

  1. Create an app at Meta for Developers (type: Business). Keep it in Development mode — no App Review needed when you are the app admin and Page admin.
  2. Copy App ID and App Secret from App Settings → Basic into the fields here.
  3. Open Graph API Explorer, pick your app, click Generate Access Token with permissions: pages_show_list, pages_manage_posts, pages_read_engagement.
  4. Paste the token here and click Fetch My Pages.
  5. Click Use as RU / Use as EN next to your pages. Done.
The app exchanges your token for a long-lived one automatically — Page tokens obtained this way effectively don't expire. Re-run this flow only if Facebook invalidates the token (password change, revoked permissions).

Setup (требует App Review Meta)

  1. IG-аккаунт должен быть Business/Creator и привязан к Facebook-странице (секция Facebook выше).

Setup

  1. Создай приложение на developers.tiktok.com
  2. Подключи продукты Login Kit и Content Posting API
  3. Включи скоупы user.info.basic и video.upload (inbox-режим, аудит не нужен)
  4. В Login Kit пропиши Redirect URI — тот же, что в поле слева
  5. Скопируй Client Key + Secret сюда → Save → Connect TikTok
TikTok требует HTTPS redirect для прод-приложений — для локалки включи Sandbox-режим приложения и добавь свой TikTok-аккаунт в target users, либо подними https-туннель (ngrok/cloudflared) и укажи его URI.
Без ключей фабрика продолжит складывать видео в render/ для ручной заливки.
