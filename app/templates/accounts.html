X / Twitter








Where to get X Client ID/Secret?
  1. Open Twitter Developer Portal → Project → App → Keys & tokens.
  2. Redirect URI: use http://127.0.0.1:8000/api/accounts/callback/x for local dev (or a public redirect if needed).
  3. Enable OAuth 2.0 (with PKCE). Required scopes: tweet.read, tweet.write, users.read, offline.access.
  4. Media upload (images/videos): you also need Consumer API Key/Secret and OAuth1 Access Token/Secret (Keys & tokens → User authentication settings → OAuth 1.0a).

How to set up YouTube API?
  1. Open Google Cloud Console → Create a project → Enable YouTube Data API v3.
  2. Create an OAuth client (Desktop App) → get Client ID/Secret.
  3. Obtain Access/Refresh tokens (via any local app/script). Paste them here.

Where to get VK Client ID/Secret and Group ID?
  1. Open VK for Developers → My apps → Create.
  2. Copy Client ID and Client Secret from app settings.
  3. Group ID: open your group page; URL like club123456 — the number is the ID.
  4. Redirect URI: you may skip and provide Access Token manually below if localhost fails validation.

How to get Bot Token and Chat ID?
  1. Create a bot via @BotFather → get the token.
  2. Add the bot to a group/channel and grant posting permission.
  3. Find chat_id: add @RawDataBot or use getUpdates API after sending a message.
