Discord

Как получить Discord Webhook URL?
  1. В Discord откройте нужный канал (текстовый).
  2. Настройки канала → Интеграции → Вебхуки → Новый вебхук.
  3. Скопируйте URL вебхука и вставьте в поле выше.

X / Twitter








Где взять X Client ID/Secret?
  1. Перейдите в Twitter Developer Portal → Project → App → Keys & tokens.
  2. Redirect URI: используйте http://127.0.0.1:8000/api/accounts/callback/x для локальной разработки (или публичный redirect при необходимости).
  3. Включите OAuth 2.0 (with PKCE). Нужны scope: tweet.read, tweet.write, users.read, offline.access.
  4. Media upload (изображения/видео): нужны также Consumer API Key/Secret и OAuth1 Access Token/Secret (Keys & tokens → User authentication settings → OAuth 1.0a).

YouTube Shorts





Как подключить YouTube API?
  1. Откройте Google Cloud Console → Создайте проект → Включите API YouTube Data API v3.
  2. Создайте OAuth client (Desktop App) → получите Client ID/Secret.
  3. Получите Access/Refresh токены (через любое локальное приложение/скрипт). Вставьте сюда.

Получить ссылку для авторизации
Получить ссылку для получения Access Token (Implicit)
Где взять VK Client ID/Secret и Group ID?
  1. Перейдите в VK for Developers → Мои приложения → Создать.
  2. Скопируйте Client ID и Client Secret из настроек приложения.
  3. Group ID: откройте страницу вашей группы, в адресе будет club123456 — число и есть ID.
  4. Redirect URI: можно не использовать и ввести Access Token вручную ниже, если сайт на localhost не проходит проверку.
