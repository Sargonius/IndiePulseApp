💡 Shorts cheat sheet — title, first second, visuals, experiment

Title

  • Not about the process: Prototyping · Layout changes · WIP · Devlog #12. Make it about a feeling or a moment in the game.
  • Hook and game name up front: the player shows ~40 Latin / ~20 Japanese characters.
  • Formulas:
    Question Would you drive this through a warzone?
    Situation Hovercar vs. the entire city
    Conflict This hovercar was a terrible idea
    Comparison Day 1 vs Day 30 of my hovercar game
  • Hashtags: 1–3 on topic, no wall of tags.

First second

  • Open mid-action: no intro, logo or fades.
  • Best moment first: the result, then the process.
  • Big hook text in the upper half, 1–2 s (✂ Editor → “＋ Hook”).
  • Sound from the first frame: a shot, an engine, music. Project fade-in — 0.

Length and ending

  • 12–25 s: hook → gameplay → peak → loop back to the start or a call to action.
  • Last 2–4 s: game name and “Wishlist on Steam” as text; UTM link in the description ({steam}) or a pinned comment.

Visuals (UE5)

  • No editor UI: Standalone or PIE in a new window. In the viewport G — game view, F11 — fullscreen.
  • Console: DisableAllScreenMessages hides warnings and debug text.
  • Native vertical beats a crop: 9:16 game window (720×1280 or 1080×1920). Shooting horizontal? Crop and zoom in on the action.
  • Main subject large and readable on a phone. Motion or an event every 1–2 s.

Experiment

  • One clip → 2–3 versions with different hooks and titles: drop the same file into the factory 2–3 times.
  • After 3–7 days, compare “Swiped away” in YouTube Studio (aim for under 50–60%) and average % viewed.
  • Note which hook won and build the next batch on it. Send the winner out with 📣 Cross-post on the board.
