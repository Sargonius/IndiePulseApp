  1. {{ mark.get(steps.api.status, '1') }} Enable YouTube Data API v3— {{ steps.api.note }}
    1. Open YouTube Data API v3 in Google Cloud ↗
    2. Click Enable. If you see Manage instead, the API is already enabled — this step is done.
  2. {{ mark.get(steps.client.status, '2') }} OAuth client (Client ID and Secret)— {{ steps.client.note }}
    1. Open Clients ↗. If a client already exists, open it; if not — + Create client → Application type Web application.
    2. Authorized redirect URIs must contain exactly this address:
      {{ redirect_uri }}
    3. Save / Create → copy the Client ID and Client secret into the fields on the left → Save.

    Google says Error 400: redirect_uri_mismatch? The address in the client doesn’t match the one above (http/https, 127.0.0.1 vs localhost and the port all matter).

  3. {{ mark.get(steps.publish.status, '3') }} Publish the app — or reconnect once a week— {{ steps.publish.note }}
    1. Open Audience ↗ (Google Auth Platform → Audience) → under Publishing status click Publish app → Confirm. It should switch to In production.
    2. Google won’t publish without a filled-in Branding page (home page, privacy policy…)? Then skip publishing: stay in Testing and reconnect YouTube once a week (step 4) — a banner shows up 2 days ahead, and a tray notification on the last day.
    3. You don’t need Google verification either way.
    4. After Publish app, still do step 4: a token issued in Testing stays a 7-day token.

    In Testing, Google issues a 7-day refresh token and reports when it expires — IndiePulse shows that in step 4. Once the app is published, the token doesn’t expire.

  4. {{ mark.get(steps.connect.status, '4') }} {% if connected %}Reconnect the channel (once a week while the app is in Testing){% else %}Connect the channel{% endif %}— {{ steps.connect.note }}
    1. {% if connected %}Reconnect{% else %}Connect YouTube{% endif %} ↗ — opens a Google tab. Also in the tray: right-click the IndiePulse icon → “YouTube: reconnect”.
    2. Pick the Google account that owns the channel{% if channel %} {{ channel }}{% endif %}. If it asks which channel to use, pick the channel, not your personal profile.
    3. The “Google hasn’t verified this app” screen is normal for your own app: Advanced → Go to … (unsafe).
    4. Tick all access checkboxes (video upload and YouTube management) → Continue.
    5. When you see “✅ YouTube connected”, close the tab and click ↻ Check again here.

    “Access blocked … has not completed the Google verification process” — the app is still in Testing, go back to step 3. Google didn’t return a refresh token? Remove the app’s access at myaccount.google.com/permissions ↗ and connect again.
