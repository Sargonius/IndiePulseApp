  1. {{ mark.get(steps.api.status, '1') }} Включить YouTube Data API v3— {{ steps.api.note }}
    1. Открой YouTube Data API v3 в Google Cloud ↗
    2. Нажми Enable. Если вместо неё кнопка Manage — API уже включён, шаг готов.
  2. {{ mark.get(steps.client.status, '2') }} OAuth-клиент (Client ID и Secret)— {{ steps.client.note }}
    1. Открой Clients ↗. Клиент уже есть — открой его; нет — + Create client → Application type Web application.
    2. В Authorized redirect URIs должен быть ровно этот адрес:
      {{ redirect_uri }}
    3. Save / Create → скопируй Client ID и Client secret в поля слева → Save.

    Google пишет Error 400: redirect_uri_mismatch — адрес в клиенте не совпадает с адресом выше (важны http/https, 127.0.0.1 или localhost и порт).

  3. {{ mark.get(steps.publish.status, '3') }} Опубликовать приложение — иначе токен умирает через 7 дней— {{ steps.publish.note }}
    1. Открой Audience ↗ (Google Auth Platform → Audience).
    2. В блоке Publishing status нажми Publish app → Confirm. Должно стать In production. Уже In production — шаг готов.
    3. Проходить проверку Google (verification) не нужно — для своего канала хватает In production.
    4. Токен, выданный пока было Testing, сам не «вылечится» — после Publish app обязательно сделай шаг 4.

    В статусе Testing Google выдаёт refresh token ровно на 7 дней, потом загрузки и статистика отваливаются с ошибкой invalid_grant. После публикации токен бессрочный.

  4. {{ mark.get(steps.connect.status, '4') }} Подключить канал— {{ steps.connect.note }}
    1. Connect YouTube ↗ — откроется вкладка Google.
    2. Выбери Google-аккаунт, которому принадлежит канал{% if channel %} {{ channel }}{% endif %}. Спросит, какой канал использовать, — выбери канал, а не личный профиль.
    3. Экран «Google hasn't verified this app» — это нормально для своего приложения: Advanced → Go to … (unsafe).
    4. Отметь все галочки доступа (загрузка видео и управление YouTube) → Continue.
    5. Появится «✅ YouTube подключён» — закрой вкладку и нажми здесь ↻ Проверить снова.

    «Access blocked … has not completed the Google verification process» — приложение ещё в Testing, вернись к шагу 3. Google не вернул refresh token — удали доступ приложения на myaccount.google.com/permissions ↗ и подключись ещё раз.
