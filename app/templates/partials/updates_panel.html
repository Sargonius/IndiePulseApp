How updates work

IndiePulse looks for a new release on GitHub 30 seconds after it starts and every 6 hours. Installing downloads the release, checks its checksum, waits until nothing is publishing, then restarts IndiePulse on the new version. If the new version doesn't come up, the previous one is put back by itself. Your settings, posts and media are never touched (they live in the data folder).

Access token (private repository)

  1. GitHub → Settings → Developer settings → Fine-grained tokens → Generate new token
  2. Repository access: Only select repositories → the repository above
  3. Permissions → Repository → Contents: Read-only (Metadata: read-only comes with it)
  4. Pick an expiration, Generate, paste it here, Save, then «Check now»
The token can only read that repository. It is kept in this app's settings and never shown in logs. A public repository needs no token.
