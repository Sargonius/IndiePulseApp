Setup Instructions

  1. OpenAI: platform.openai.com/api-keys → Create new secret key
  2. Claude: platform.claude.com → API keys → Create Key
  3. DeepL: deepl.com → API keys (the free plan's keys end with :fx)
  4. Paste the key, Save, then Test
All optional. The translate buttons and the outreach letters use the AI picked above; without one, or when it fails, machine translation: DeepL with a key, otherwise the free public translators.
Models: gpt-6-luna is OpenAI's cheap current one; claude-opus-5-5 is Claude's best (claude-sonnet-5-5 and claude-haiku-5-5 cost less). Test tries the model typed above before you save it. Keys are kept only in this app's settings, on this drive.
