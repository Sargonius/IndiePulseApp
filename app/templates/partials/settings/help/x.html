Setup Instructions

  1. Open X Developer Console
  2. Create app, enable OAuth 2.0 with PKCE
  3. Set Redirect URI to your callback URL
  4. Copy Client ID and Secret
  5. For media uploads: also get OAuth 1.0a keys
  6. Buy API credits (Billing) — without them X answers 402
Scopes needed: tweet.read, tweet.write, users.read, offline.access
