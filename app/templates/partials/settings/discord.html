Setup Instructions

  1. Open Discord, select your server and text channel
  2. Channel Settings → Integrations → Webhooks → Create Webhook
  3. Copy the Webhook URL
  4. Paste URL and click "Save"
  5. Click "Test" to verify

Reactions analytics (optional)

  1. Developer Portal → New Application → Bot → Reset/Copy Token
  2. OAuth2 → URL Generator → scope bot, permissions View Channel + Read Message History
  3. Open the generated link, add the bot to your server
  4. Paste the Bot Token above and click "Save bot token"
