💳 X API billing

Balance & top-up ↗ {% if connected %}{% endif %}

The X API is prepaid: you buy credits in advance in console.x.com → Billing, and every request deducts them right away. When the balance hits zero, X answers 402 credits depleted to everything: tweets fail, X stats and followers freeze. IndiePulse then shows a red banner at the top and a tray notification.

X Premium on the account is a separate subscription: it lifts the 280-character limit but doesn’t top up the API balance.

Keep a 402 from hitting mid-campaign

  1. Auto-recharge in console.x.com → Billing: a threshold (e.g. $2) and a top-up amount — the balance never hits zero.
  2. A monthly Spending limit — a ceiling so a glitch can’t burn through the balance.
  3. A link in an X post costs as much as 13 tweets — use {steam} only where the post really leads to Steam.
  4. After topping up, click “Check” (here or in the banner), then Jobs → Retry for the posts that didn’t go out. IndiePulse won’t retry them on its own: an empty balance isn’t a network glitch.
