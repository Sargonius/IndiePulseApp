# Инструкции по обновлению проекта

## Изменения в этом обновлении

1. **Telegram** - разбиение длинных сообщений
2. **Видео рендер** - горизонтальный и вертикальный форматы
3. **Сжатие видео** - автоматическое сжатие под лимиты платформ
4. **TikTok API** - интеграция с Content Posting API
5. **Новые поля в БД** - `media_normal_path` и `media_vertical_path`

## Шаги для запуска проекта после обновления

### 1. Установите новые зависимости

```bash
pip install -r requirements.txt
```

Новая зависимость: `pydub` (для обработки музыки)

### 2. Обновите базу данных

SQLModel должен автоматически создать новые столбцы при первом запуске.
Если возникнут проблемы, можно удалить `indiepulse.db` (ВНИМАНИЕ: потеряются данные!)
или добавить столбцы вручную:

```sql
ALTER TABLE briefs ADD COLUMN media_normal_path TEXT;
ALTER TABLE briefs ADD COLUMN media_vertical_path TEXT;
```

### 3. Настройте музыкальную папку (опционально)

В настройках (`.settings.json`) добавьте:

```json
{
  "music_dir": "E:\\SynthSocial\\Music"
}
```

Или любой другой путь к папке с музыкой для видео.

### 4. Настройте TikTok (опционально)

Если хотите использовать TikTok API:
1. Зарегистрируйте приложение на https://developers.tiktok.com/
2. Добавьте в настройки:
   - `tiktok_client_key`
   - `tiktok_client_secret`
3. Подключитесь через `/api/accounts/connect/tiktok`

### 5. Запустите проект

Дважды щёлкните `IndiePulse.pyw` (или ярлык IndiePulse) — появится значок в трее.

## Что изменилось в работе

### Видео рендер
- Теперь на странице News есть новая секция "Video Render"
- Можно рендерить отдельно горизонтальное (16:9) и вертикальное (9:16) видео
- Выбор музыки из локальной папки
- Настройка crop, zoom, fade-in/fade-out

### Публикация видео
- **Горизонтальные платформы** (VK, X, Discord, Reddit, Telegram, Facebook) используют `media_normal_path`
- **Вертикальные платформы** (TikTok, YouTube Shorts) используют `media_vertical_path`
- Видео автоматически сжимается если превышает лимиты платформы

### Telegram
- Длинные тексты (>4096 символов) автоматически разбиваются на несколько сообщений по предложениям
- Caption в фото/видео тоже разбивается если >1024 символа

## Проверка работоспособности

После запуска проверьте:
1. Сервер запустился без ошибок (логи в `logs/server.out.log`)
2. Worker запустился без ошибок (логи в `logs/worker.out.log`)
3. Страница `/news` загружается и показывает секцию Video Render
4. Можно создать пост и он публикуется

## Известные проблемы

Если проект не запускается:
1. Убедитесь что все зависимости установлены: `pip install -r requirements.txt`
2. Проверьте логи: `logs/server.err.log` и `logs/worker.err.log`
3. Проверьте что база данных обновлена (см. шаг 2)

## Откат изменений

Если что-то пошло не так, можно откатить изменения:

```bash
git checkout HEAD -- .
```

Или восстановить конкретные файлы из последнего коммита.
